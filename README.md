# alisen-card-assets

Картинки для карточек ALISEN на маркетплейсах. Только то, что видит покупатель. Документы, цены, данные поставщика сюда не кладём.

Папка = артикул продавца:
- `raw/` не используется: исходные фото со склада в публичный репозиторий не кладём
- `cutout/` товар без фона, PNG
- `scenes/` сцены без текста (ChatGPT)
- `export/` готовые слайды 900×1200

Имя файла: `<цвет>_<тип>_<ракурс>.png`, например `black_cutout_front.png`. Это имя становится именем слоя в Figma.

Ссылка для браузера: `https://raw.githubusercontent.com/imaltsevlab-dotcom/alisen-card-assets/main/<путь>`
